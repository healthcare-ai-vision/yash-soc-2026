## Week-5 to Week-8 (Final Project)
The problem statement of the final Endterm Project is about Training a Classification Model using pytorch library that identifies/labels the skin disease. The dataset used here is the ISIC 2019 dermatology skin lesion images and are used to train the model. The various Disease variants that this model is trained to identify are:
- i) Melanoma (MEL)
- ii) Melanocytic Nevus (NV)
- iii) Basal Cell Carcinoma (BCC)
- iv) Actinic Keratosis (AK)
- v) Benign keratosis (BKL)
- vi) Dermatofibromea (DF)
- vii) Vascular lesion (VASC)
- viii) Squamous Cell Carcinoma (SCC)
The project file at end also predicts several accuracy and data loss scores at end.
